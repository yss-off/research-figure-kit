# Task-specific visual research before plotting

Research style after defining the scientific question and choosing an honest encoding, and before writing the plotting code. Match the actual figure type, audience, venue, medium, and viewing size; a style suitable for a neural-network diagram is not automatically suitable for a paired-comparison plot, spectrogram, or uncertainty panel.

Inspect actual figures from closely related work and applicable official publisher guidance. A small set of relevant precedents is normally enough. Record source URL/path, version/date when known, figure locator, what was actually inspected, and useful/rejected design features. Do not infer appearance from an abstract or repeatedly cite unrelated famous papers. Separate official requirements from local recommendations. Use available permitted browsing or inspected local references; if unavailable, disclose provisional choices instead of pretending verification. No plotting script acquires a network dependency.

Before coding, save a short task-local style brief alongside the existing figure contract. Include panel arrangement, alignment, font ladder at the intended printed/display size, palette roles, markers/line styles, legends/direct labels, whitespace, export class, and the source observations behind those choices. Consider hierarchy, density, and reader effort, not just colors. Reuse and recheck a matching brief for small edits; refresh when the task/medium changes or a poor result reveals a mismatch. Discuss first when the user requests that checkpoint; otherwise make reversible presentation choices within scope.

Borrow abstract visual principles rather than source artwork. Keep statistical meaning and data intact: axis limits, normalization, uncertainty definitions, binning, missing values, and exclusions cannot be changed merely to imitate a look. Do not copy an architecture palette into continuous-valued heatmaps; choose qualitative/sequential/diverging colors according to the data. Avoid decorative 3D and excessive effects. A journal-branded preset does not prove compliance.

After export, inspect the actual artifact at target size for hierarchy, alignment, label readability, balanced whitespace, legend load, and redundant encodings; compare it with the brief. Grayscale and color-vision checks remain relevant where required, and a single palette flag is insufficient. Keep visual judgment, file/metadata checks, scientific accuracy, and user acceptance separate. The existing publication and visual-review references continue to govern validation.
